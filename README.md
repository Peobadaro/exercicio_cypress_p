# Exercício módulo 34 – Testes com Cypress

Testes end-to-end da [Agenda de contatos](https://ebac-agenda-contatos-tan.vercel.app/): inclusão, alteração e remoção de um contato.

## Como rodar

```
npm install
npm test               # roda os testes no terminal
npm run cypress:open   # abre a interface do Cypress
```
